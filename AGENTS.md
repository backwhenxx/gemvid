# Инструкция для ИИ-агента (Gemini CLI, Jules и др.)

Правила канала «ШТА?!» — в `CLAUDE.md` (читать обязательно: стиль, длина, финал, комментарии, обложка).
Эталон качества — эпизод `episodes/plotina`. Общение с Денисом — по-русски, коротко.
Перед необратимыми действиями спрашивать. Файлы без разрешения не удалять.

## Как устроено
- Видео собирает **GitHub Actions** (`.github/workflows/render.yml`): Remotion + three.js → mp4 1080×1920,
  обложка `cover.png`, превью → раздел **Releases**. Локально ничего рендерить не нужно.
- Эпизод = папка `episodes/<slug>/` с `episode.json` (сцены) и `voice.mp3` (озвучка).
- Сцены лежат в `src/scenes/` (3D-миры: `dam/`, `trench/`). Новый 3D-мир — копировать структуру
  `src/scenes/dam/DamScene.tsx` (статичный мир + динамическая группа по кадрам + кэш неизменной геометрии).
- Нужен установленный и залогиненный `gh` (GitHub CLI).

## Процесс нового ролика
1. Идея (или повтор видео Дениса «точь-в-точь», если он прислал своё) → сценарий.
2. Текст для ElevenLabs одним блоком с тегами эмоций в [скобках] (2–4 смены подачи за ролик, без [fast]),
   паузы «...» и «—», числа словами, финал «Подпишись». Памятка Денису: модель Eleven v3, голос «Евгений»,
   вставить как есть, один дубль, прислать MP3. Самому голос не генерировать.
3. Пока Денис делает озвучку — написать `episodes/<slug>/episode.json`:
   у каждой сцены `say` = точный кусок текста, `type`, `props`; все сцены кроме первой `"cont": true`;
   `"captionStyle": "word"`, `"autoOutro": false`, `"cover": {...}`, звуки `ambience` / `props.sounds`
   (Openverse, запросы конкретные по-английски).
4. Быстрая проверка картинки без голоса (≈5 мин):
   `gh workflow run render.yml -f episode=<slug> -f stills=true` → `git pull` → смотреть `out/<slug>/stills.jpg`.
5. MP3 → `episodes/<slug>/voice.mp3`, коммит с `[skip ci]` в сообщении, `git push`, затем один запуск:
   `gh workflow run render.yml -f episode=<slug>`
   (без `[skip ci]` push сам запустит рендер — тогда второй запуск не нужен).
6. Ждать: `gh run watch` (2D ≈ 15 мин, 3D ≈ 60–90 мин).
7. Скачать: `gh release download <slug>-<номер> -D out/release` (номер — в `gh release list`).
   Проверить контакт-лист: `ffmpeg -i v.mp4 -vf "fps=1/3,scale=180:-1,tile=8x4" -frames:v 1 s.jpg`
   и громкость `ffmpeg -i v.mp4 -af ebur128 -f null -` (≈ −14 LUFS).
8. Отдать Денису: mp4 + `cover.png`, название, описание с хештегами, закреплённый комментарий
   (выбор/прогноз из 2–3 вариантов, чтобы зрители спорили).

## Другие режимы workflow
- `-f cover_only=true` — только обложка; `-f sounds_only=true` — проверить подбор звуков;
  `-f demo_voice=true` — тестовый голос, если MP3 не будет.
- Расшифровать СВОЁ видео: положить аудио в `research/x.mp3` →
  `gh workflow run transcribe.yml -f file=research/x.mp3` → `research/x.json`.
  **Чужое аудио и его расшифровки в репо не класть** (репо открытый — авторские права): расшифровывать вне репо.

## Лимиты
Бесплатно 2000 минут Actions в месяц (приватный репо). Не гонять лишние полные рендеры —
сначала `stills`, потом один финальный.
