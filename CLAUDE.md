# Правила для Claude в этом репо

Это фабрика шортсов для канала «ШТА?!» (@eto_shta). Claude — вся команда: идея, сценарий, сборка.
Общение по-русски, коротко. Перед необратимыми действиями — спросить. Файлы без разрешения не удалять.

## Процесс нового ролика
1. Придумать **новую** идею с нуля. Темы, которые приводит Денис, — примеры стиля, не темы для повтора.
   Тема не должна быть общеизвестной. Лучше всего заходит «как устроено / скрытый механизм в разрезе».
2. Создать `episodes/<slug>/episode.json` (формат и сцены — в README).
3. Прислать Денису текст для ElevenLabs: голос «Евгений», теги эмоций в [скобках], **один** дубль.
   Ждать его mp3 — самому озвучку не генерировать.
4. Положить mp3 в `episodes/<slug>/voice.mp3`, закоммитить, запушить в `main` → рендер в Actions.
5. Проверить `out/<slug>/preview.jpg` и лог; отдать ссылку на Release.

## Обязательно в каждом ролике
- Длина **от 45 секунд**, без спешки. Озвучки вдвое меньше прежнего, короткие паузы, без длинных немых кадров.
- Хук в первые секунды; «захват внимания» каждые 3–5 секунд (смена сцены, число, физика).
- Предмет ролика назвать вслух рано и **одновременно** показать на экране.
- Не начинать раз за разом с шёпота.
- Финал — короткое «подпишись». Никогда «отправь другу».
- Без полосы прогресса сверху. Субтитры на y≈1330 (уже так в коде).
- Палитра нейтральная, научная: тёмный фон, «бумага», приглушённый серо-стальной акцент (не ярко-синий); мягкий янтарный — только тепло/опасность. Розовый — только «?!» в логотипе. Без неона и свечений.
- Обложка: `cover` в episode.json (строки заголовка + подзаголовок) → `out/<slug>/cover.png`, отдавать вместе с видео.
- Без маскота. Без текста лицензий/атрибуции в кадре.
- Нужен узнаваемый город — Нью-Йорк или Шанхай, не Москва.
- Если просят «такую же графику, как в примере» — повторять тот стиль, не придумывать свой.
- Если что-то нельзя сделать ровно как просили — сначала сказать и предложить замену, ждать «да».

## Ассеты
- Картинки/клипы от Дениса (Nano Banana, Veo 3) — в папку эпизода, сцены `image`/`video`.
- 3D-модели: исходники в `assets/models/raw/`, затем `npm run models:optimize`, в сцене `"model": "имя.glb"`.
